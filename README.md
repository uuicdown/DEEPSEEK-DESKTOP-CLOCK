> 一款专为 DeepSeek 开发者、AI 工程师及调用用户打造的高颜值峰谷时段追踪看板与桌面挂件。

## ✨ 核心特性

- **⏱️ 毫秒级多时区数字时钟**：
  - 支持毫秒动态显示、12/24 小时制切换。
  - 支持全球主要时区（北京时间 UTC+8、UTC、纽约、旧金山、伦敦、巴黎、东京等）一键切换，并同步显示基准北京时钟。
- **🎯 峰谷状态实时感知（梁文峰 vs 梁文谷）**：
  - **高峰原价（梁文峰 · 100%）**：每日北京时间 09:00 - 12:00、14:00 - 18:00（高并发业务高峰）。
  - **空闲特惠（梁文谷 · 5折 50%）**：每日北京时间 00:00 - 09:00、12:00 - 14:00、18:00 - 24:00，以及周末全天。
- **📈 动态 24 小时峰谷时间轴**：
  - 纯净呈现「当前时区日夜（☀️日 / 🌙夜）+ 峰谷（峰 / 谷）」精准分段。
  - 实时指示针与进度百分比高亮，一眼看清全天分时结构。
- **⏳ 状态切换倒计时**：精准预告距离下一次峰谷切换的剩余时分秒与目标阶段。
- **🪟 极简悬浮小时钟（Mini Widget）**：
  - 支持一键收缩至屏幕右下角极简挂件，纯净显示「时间 + 梁文峰/谷状态」。
  - 支持自由拖拽位置与一键恢复全屏看板。
- **🎛️ 沉浸全屏时钟模式**：
  - 极简全屏大字时钟，支持键盘 `ESC` 退出，适合作为工作台常驻大屏看板。
- **💰 实时 Token 费用与省钱测算器**：
  - 支持输入/输出 Token 数量与 KV Cache 缓存命中率自由配置，实时估算高峰与低谷成本及立省金额。
- **🌐 多语言支持（i18n）**：
  - 简体中文（梁文峰 / 梁文谷）
  - English（Liang Wenpeak / Liang Wentrough）
  - Русский（Пиковый Лян / Долинный Лян）
- **🎨 4 套精选质感主题**：深空蓝（Deep Blue）、极客暗黑（OLED Dark）、琥珀金（Amber Gold）、赛博霓虹（Cyber Neon）。

## 🚀 本地开发与部署

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```
启动后访问 `http://localhost:3000` 即可实时预览。

### 3. 构建生产包
```bash
npm run build
```
编译产物将输出至 `dist/` 目录，可直接部署至任何静态托管平台（如 Vercel、Cloudflare Pages、GitHub Pages、Nginx 等）。

## 💡 最佳使用建议

1. **批量任务错峰运行**：将离线批处理、数据集清洗与合成、模型 Evaluation 等重度 Token 消耗任务调度至每日 **18:00 之后** 或 **12:00 - 14:00** 进行，直接立省 50% 预算。
2. **常驻挂件监控**：点击顶部「缩小」按钮开启右下角悬浮小窗，在编码或跑脚本时随时了解当前计费窗口。
